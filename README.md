# ZHS Audit Dashboard

Dashboard laporan audit website Zam-Zam Hidden Spot (ZHS) dan evaluasi Supply Chain Management.

## Isi project
- `index.html` — struktur dan konten dashboard
- `css/style.css` — desain, layout, responsivitas, dan print stylesheet
- `js/main.js` — navigasi sidebar dan interaksi menu mobile
- `js/charts.js` — grafik ringkasan, prioritas, framework, dan readiness
- `assets/logo-zhs.png` — logo utama ZHS
- `assets/favicon.png` — favicon browser

## Menjalankan
1. Ekstrak folder ZIP.
2. Buka folder `ZHS-Audit-Dashboard` di Visual Studio Code.
3. Jalankan `index.html` menggunakan ekstensi Live Server.
4. Pastikan koneksi internet aktif agar Google Fonts dan Chart.js dari CDN dapat dimuat.

## Export PDF
Klik tombol **Export PDF** di bagian kanan atas, lalu pilih printer **Save as PDF** pada dialog browser.

## Catatan data
Skor framework dan readiness merupakan penilaian analitis sesuai rancangan audit, bukan hasil survei atau sertifikasi. Diagram prioritas P0/P1/P2 merupakan visualisasi kelompok rekomendasi, bukan ukuran kuantitatif jumlah pekerjaan.
